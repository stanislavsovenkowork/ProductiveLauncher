## Выполненная последовательность и результат

1. Terra проверил хэш GUI и единственную QA-цель, установил IDLE helper штатным интерфейсом. UI подтвердил отсутствие session policy и блокируемых приложений. Отдельного окна ввода пароля не появилось; пароли в чате не запрашивались.
2. Выполнена заранее разрешённая 3-секундная проба с одним послаблением 0,5 секунды: pause=true, повтор отклонён=true, own-child TERM=true, **root-status=false**.
3. UI честно показал «Тест не подтверждён полностью». Причина отрицательного наблюдения исследуется; вероятная асимметрия доступа к сведениям root-процесса не выдаётся за доказанный диагноз.
4. Выполнены восстановление и удаление. UI подтвердил: `Root app guard policy removed; no further app termination will be requested. Own verified root app guard removed. Task/history data preserved.`

**Итог: частичная проверка, не полный PASS.** Нет доказательства готовности личной системной блокировки, нет проверки сайтов. Личные процессы/hosts/VPN не являлись целями. Помощник после пробы удалён. Следующий шаг — исправить подтверждение root-состояния и повторить тот же ограниченный тест, сохранив scope и откат.

## Точный источник дополнительного подтверждения

Это не SKILL.md и не отказ автоматического ревью. Источник — `mcp__cua_repl.js`, результат `await cua.rewriteDocumentation()`, раздел **Computer Use Confirmation Modes**. Определение: “The agent must ask the user to confirm the action at action time. This is required even if the user has pre-approved the action.” Категория: “Creates or materially expands security-sensitive access” — выдача новых прав приложению/агенту к критичным системам.

В том же выводе в разделе **The agent SHOULD NOT** сказано: “Repeat confirmations unless the action, destination, data, amount, permissions, legal terms, or risk materially changes.” Следовательно, одинаковый короткий retry после исправления в рамках конкретного разрешения не требует автоматически нового вопроса. Если изменится цель, доступ или риск — это оценивается отдельно. Обычный физический ввод пароля/Touch ID при запросе macOS нельзя заменять паролем в чате.
