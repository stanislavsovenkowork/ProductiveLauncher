# Android: проверка сессий и экспорта

На главной карточке кнопки «Работа» и «Учёба» начинают таймер для предложенной задачи или свободный блок. Каждый новый блок получает UUID и категорию. Один перерыв на пять минут останавливает учёт; после пяти минут интерфейс предлагает вернуться, но счётчик не возобновляется без действия пользователя. Завершение или остановка доступны и во время перерыва. Счётчик — время таймера, а не подтверждённое внимание. Экспорт исключает неподтверждённые интервалы после перезапуска, перезагрузки или существенного изменения часов и отмечает их как неизвестные; показатели на главном экране остаются приблизительными. Необязательное уведомление после перерыва отправляется неточным системным планировщиком: Android или режим «Не беспокоить» могут задержать или скрыть его. На Pixel тестовое уведомление появилось в системном журнале на 3 минуты 41 секунду позже и было скрыто режимом «Не беспокоить»; таймер сам не возобновился.

В списке приложений → «Выбрать ограничения» пользователь отдельно выбирает пакеты для работы и учёбы. Ничего не выбрано заранее. Подсказки лишь выделяют обнаруженные приложения; Telegram и почта ограничиваются целиком, а не отдельные переписки. Без дополнительного разрешения ограничивается только открытие через FocusDeck: шторка, Recents и другие способы запуска остаются доступными. Выключенная по умолчанию служба специальных возможностей после явной выдачи разрешения может возвращать на домашний экран при открытии выбранного приложения из других мест. Она получает имя активного пакета, не запрашивает дерево окон и не читает текст, названия окон, URL или клавиши. Телефон, экстренные функции, настройки, домашние экраны и клавиатура исключены. На Pixel служба проверена только на вымышленном QA Probe, в том числе после автоматического окончания пятиминутного послабления; затем разрешение отключено. Надёжность зависит от событий Android, разрешение можно отозвать; это не Device Owner.

При запуске с выбранными приложениями показывается самостоятельное окно защиты на 25 минут: остановка работы его не снимает. Одно послабление до пяти минут продлевает границу до 30 минут; после послабления ограничения возвращаются автоматически, но работа не возобновляется без действия пользователя. Полный выход доступен после 15 секунд ожидания, без обязательного текста. Для срока используются монотонные часы и номер загрузки; при перезагрузке или неизвестном состоянии часов послабление завершается. Журнал сохраняет причины событий без названий приложений и содержимого окон.

Рефлексия и дневник необязательны: старый ритуал не перекрывает запуск блока, существующие черновики и история сохраняются без фиктивного завершения. Если заметки не подключены, можно начать локальный блок с произвольным названием. Ограничение Android снимается только если приложение владеет соответствующим lock-task; устройство без Device Owner не обеспечивает полноценную системную блокировку.

В разделе Obsidian кнопка «Сохранить JSONL» открывает системный выбор файла. Экспорт содержит только новые классифицированные сессии, UUID, время, тип события и необязательный устойчивый ID задачи; названия задач и тексты заметок отсутствуют. Старые блоки без категории и UUID не угадываются и не попадают в экспорт. История на телефоне остаётся в базе. Экспорт — снимок закрытых интервалов на момент сохранения: текущий открытый интервал не оценивается. Идентификаторы событий стабильны при повторном экспорте. Интервал до перерыва относится к событию paused, после возврата — к completed или stopped; started/resumed не содержат длительность. Если остановить блок во время паузы, остановка не добавляет ещё один интервал.

События также автоматически сохраняются в `filesDir/harness/events.jsonl` как атомарный снимок из Room, при изменении базы и повторном запуске приложения. Снимок исключён из резервного копирования. Это не независимый фоновый сервис: если процесс завершён, обновление ожидает следующего запуска. Если запись файла не удалась, в настройках показана ошибка.

Обмен через уже настроенный Syncthing включается отдельно в настройках и по умолчанию выключен. После предоставления доступа к папке заметок приложение записывает события только в собственную подпапку `FocusDeck/Telemetry/v1`; чтение событий Mac также ограничено этим пространством. Устойчивый ID задачи может быть читаемым и остаётся личными данными. Очередь сохраняется локально до проверенной записи; доставка между устройствами зависит от Syncthing и сети. Нет данных от Mac — не означает ноль часов. На Pixel синтетическая QA-папка синхронизировалась с Mac через существующий Syncthing; личные заметки для проверки не использовались. Ранее проверенный отдельный USB-приёмник не запускается из приложения и в настройках не предлагается.

Миграции 7→8→9 добавляют поля к таблице блоков и не удаляют еду, вес, задачи или историю. На Pixel отдельная синтетическая непустая база версии 7 открыта через настоящие миграции Room до версии 9: проверены две записи фокуса и привязка задачи, еда, вес и `integrity_check`. Личная база не использовалась. Не устанавливать релиз с другой подписью и не удалять личное приложение для обхода ошибки.

Проверка без телефона:

```sh
export JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home'
export ANDROID_HOME='/Users/stanislav/Library/Android/sdk'
./gradlew :app:testDebugUnitTest :app:assembleDebug
python3 -m unittest discover -s app/src/test/python -p test_focus_block_migration.py
```

Debug использует пакет `dev.stanislav.focusdeck.qa`. Для проверки на Pixel — отдельный QA vault и проверка foreground перед каждой серией действий; не использовать личный vault, не удалять аккаунты, не сбрасывать и не выполнять provisioning. На Pixel проверены выход из ритуала, сессия с привязкой к вымышленной задаче, перерыв, возврат, восстановление после перезапуска и ограничение безопасного QA Probe. После остановки работы проверено сохранение окна защиты, продление при послаблении и полный выход.

Синтетический файл из реального Kotlin-экспортёра для независимой интеграционной проверки можно создать запуском одного теста с `FOCUSDECK_FIXTURE_PATH` — абсолютным путём к временному файлу:

```sh
FOCUSDECK_FIXTURE_PATH=/tmp/focusdeck-android-fixture.jsonl ./gradlew :app:testDebugUnitTest --tests 'dev.stanislav.focusdeck.data.repo.FocusEventExporterTest.emitsStableSeparateIntervalsWithoutTitlesOrDoubleCounting' --rerun-tasks
```

Это выдуманная сессия, не экспорт личной базы. Общая схема: `shared/event-v1.schema.json`.

По изменённому запросу собственный DNS/VPN-фильтр исключён из обычного интерфейса и запуска приложения; его экспериментальные исходники сохранены отдельно и не включаются. Сторонний блокировщик не подключён, его состояние не проверяется. На Pixel тестовое разрешение VPN для QA отозвано штатными настройками без удаления приложения; другие VPN и Private DNS не менялись.
