## Что действительно проверено

- **Mac именно этой сборки:** Terra прошёл изолированный UI-цикл синтетическая задача → учёба → старт → пауза → явное продолжение → остановка → reopen с сохранённой задачей. Внешняя защита честно «не подключена». Подпись ad-hoc проверена; root-helper, browser worker и systemextension не вложены. Новые незавершённые gate/publisher-изменения исходников в этот снимок не вошли.
- **Android именно этой сборки:** 308 unit-тестов успешны; установлена поверх только `.qa`. После force-stop и обычного повторного открытия фоновое задание48734 восстановилось в waiting. Это доказательство восстановления задания, а не гарантированного срока его выполнения системой. Предыдущая core-сборка отдельно прошла старт без обязательного ритуала; весь UI после последней sync-пересборки ещё не повторён.
- **Данные:** отдельная непустая миграция Room7→9 на Pixel сохранила2focus/1meal/1weight, schema/integrity OK; личная база не использовалась. В предшествующих QA проверены taskRef, pause/return/restart, остановка в паузе; задача не помечалась готовой автоматически.
- **Автоматический транспорт:** через существующий Syncthing реально получены3 SHA256-проверенных batch с32 синтетическими Android-событиями,0 невалидных/частичных/конфликтных. Это отдельная пустая QA-папка, без USB/HTTP-копирования и без включения в личную статистику. Реальный краткий disconnect/reconnect ещё проверяется и не объявляется пройденным этим снимком. Обратный Mac→Android publisher не готов.
- **Метрики/сопровождение:** текущий источник имеет67 Python-проверок; отдельно прошли6 межплатформенных сценариев и9 Swift-проверок чтения выбранной заметки. Пересечения устройств не удваиваются, паузы/неизвестные/будущие часы различимы, дубли/конфликты проверяются. На Mac независимо установлены review/loopback receiver/passive context; upgrade с backup сохранил данные, runtimeIntegrity=verified, реальный review завершился с exit0. Production Android-root пока missing, без ложного cachedPriorReceipt; QA исключена. Это проверка установленного контура, он не является содержимым ZIP.

Optional Mac Focus: UI-probe сохранил DND, CLI зависал; готовым/подключённым его не считаем.

## Что мешает финальной приёмке

1. Полный повтор актуального Android UI, очередь при реальном разрыве/восстановлении и системном сне, проверка фоновой доставки без ручного запуска. Само состояние waiting не доказывает доставку.
2. Готовый обратный Mac→Android транспорт и понятные статусы связи в обеих программах. Первая односторонняя доставка не равна синхронизации активного состояния сессий.
3. Завершение onboarding/обновления/отката и повтор проверок финальных исходников. Этот beta-снимок не является личным Android release; откат старого APK поверх новой схемы БД не проверен и не предлагается.
4. Независимый добровольный канал возврата после полного удаления ещё не выбран. После удаления всех участников автоматический возврат не обещается.
5. Личный пилот не начат: нет согласованных дат, исходного сравнения и измеренной полноты наблюдения. Прирост сосредоточенных часов не доказан.

## Установка и границы

Распакуйте ZIP и откройте FocusDeck.app; APK устанавливайте как отдельный FocusDeck QA, не удаляя личный FocusDeck. Пошаговые действия/выход/история — INSTALL-AND-RECOVERY.md. Не отключайте безопасность macOS ради запуска. Mac-сборка ad-hoc для локальной разработки, не публичный notarized-релиз.

Таймер измеряет учитываемый интервал, не внимание. Нет данных ≠ ноль работы. 25/5мин — параметры инженерной гипотезы. taskRef может быть читаемым slug и является личными метаданными; транспорт ограничен собственной папкой пользователя. В поставке нет личных vault/БД/секретов или обязательных лабораторных фильтров. Root-helper удалён; QA Accessibility/VPN выключены, VPN-разрешение снято; личные VPN/Private DNS и основной release не менялись.

Разработка продолжается после этого снимка; полный список требований — ACCEPTANCE.md.
