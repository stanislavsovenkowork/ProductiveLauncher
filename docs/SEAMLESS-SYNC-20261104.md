# FocusDeck — задачи и живое обновление, 4 ноября 2026

Установлены Mac 0.12/build15, Android 1.2.1/code4 и Obsidian FocusDeck panel 0.3.2.

## Что изменилось

- Mac: отдельная кнопка «Задача выполнена · отметить в Obsidian» меняет только галочку задачи в выбранной заметке. Обычное завершение отрезка задачу не закрывает. Уникальный ID, свежее чтение и сверка названия защищают от отметки другой/удалённой задачи; повторная отметка идемпотентна. Контекст источника сохраняется после перезапуска.
- Mac: запоминается выбранная заметка; список и состояние связанной задачи перечитываются каждые 2 секунды. Непрочитанный источник помечается как недоступный, прежний список не выдаётся за свежий. Можно выбрать другую заметку.
- Android: пока Activity на экране, открытый день и сегодняшний день перечитываются примерно каждые 2 секунды, цели/проекты — каждые 3 цикла. Пауза при открытой клавиатуре; в фоне цикл остановлен. Для целей нет повторного чтения всей истории активности и мигающего индикатора загрузки. Существующие черновики и проверки конфликтов сохраняются.
- Obsidian: панель читает свежую дневную заметку, реагирует на переименования, возвращение в окно и видимость. Обновление при наборе текста по-прежнему откладывается до выхода из поля.
- Существующий Syncthing Fork на Pixel запущен штатно. Новый транспорт, облако, ADB reverse не создавались. Защита Pixel остаётся у Stay Focused; её настройки и Accessibility не менялись. Root-защита Mac не менялась: исполняемый helper имеет прежний SHA256; штатная установка зарегистрировала подпись нового интерфейса один раз.

## Что действительно проверено

- Настоящий UI Mac: выбор собственной заметки, завершение задачи без запуска таймера, повторное открытие запомненной заметки без файлового диалога, исчезновение выполненной задачи из открытых.
- Завершение с Mac дошло на Pixel байт в байт через Syncthing. Изменение собственной заметки на Pixel дошло обратно на Mac и появилось в уже открытом списке без ручного обновления. Контрольная задача и остальной текст сохранились.
- Отдельный замер доставки нового изменения Mac → Pixel: **4,92 секунды**. Это один замер при работающих устройствах/связи, не SLA. При первом обратном замере наблюдатель попал на краткую замену файла; точную обратную задержку не записали, последующие байты и UI совпали.
- Obsidian: после штатного перезапуска UI подтвердил FocusDeck 0.3.2 и включённый плагин. Его файлы автоматически дошли и на Pixel. Ошибка другого плагина obsidian-mind-map показана при старте; он не менялся.
- Android: release собран, lintVital завершён, подпись сравнена с прежним установленным APK. Обновление install -r успешно, без удаления приложения. Основной экран release 1.2.1 открылся без наблюдаемой ошибки/миграционного диалога. Изменение данных открытого Android-экрана внешней записью отдельно не принималось; проверены доставка файлов, код обновления и запуск приложения.
- Проверки изменённого Mac-адаптера: точная галочка/Unicode/CRLF/метаданные, перестановка строк, повторная отметка, отказ при отсутствующем/дублирующемся ID и изменённом названии, восстановление старого контекста. Swift build/codesign и JS syntax прошли.

## Границы и уборка

Syncthing должен работать на обоих устройствах. Сон, отсутствие сети, остановка службы и Android-ограничения могут задержать доставку; абсолютный realtime/автоматическое разрешение одновременных конфликтных правок не обещаются. Факт локального чтения файла не означает свежую доставку с другого устройства. Полная синхронизация активных таймеров/системной root-политики не добавлена. Никаких новых Android-блокировщиков.

Собственная QA-заметка архивирована в поставку и удалена из vault; прежний Mac-контекст восстановлен, QA scope закрыт. Личные задачи не отмечались, история не переименована в baseline. Pixel/сеть/USB/VPN не перезапускались и не перенастраивались. Старые приложения и снимки сохранены. Исходники изменялись только в ce11; Desktop получил документацию.
