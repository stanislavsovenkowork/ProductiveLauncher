## Как читать статусы

- **Есть в коде** — найдена конкретная реализация. Это не автоматическое подтверждение её работы на каждом устройстве.
- **Исторически проверено** — есть датированный отчёт; его условия и пределы не переносятся на новые версии без проверки.
- **Эксперимент / QA / legacy** — исходники сохранены для полноты; не инструкция включать этот механизм в личной среде.
- **Запланировано** — карточка бэклога, функция ещё не реализована.

Актуальный бэклог: [карточки 3–7](../PRODUCT-INCREMENTS.md). Исследовательские основания: [BEHAVIOR-EVIDENCE.md](../BEHAVIOR-EVIDENCE.md). Старые спецификации и отчёты остаются в [общем каталоге](../README.md); при расхождении текущего кода и старого отчёта нельзя автоматически считать отчёт актуальным.

## Границы продукта

Android использует уже настроенный Stay Focused; собственную защиту не включать и его настройки не менять. Системный запрет Mac независим от сеанса. Остановка таймера и закрытие UI не являются штатным снятием активного запрета; владелец с root всё же контролирует ОС.

Минуты таймера, зарегистрированный контекст и подтверждённый полезный результат — разные данные. Отсутствие событий не равно нулю работы. Научные публикации не доказывают эффективность FocusDeck целиком или гарантированный рост рабочих часов.
