# FocusDeck на macOS

## Назначение и статус

Основная сборка — **FocusDeck System 0.12.2 / build 17**, SwiftUI, минимальная версия macOS 15. Её создаёт [build-system-app.sh](../../macos-study/build-system-app.sh). В том же дереве сохранены старые candidate, root/user-agent и QA-варианты: это разные конфигурации, их поведение не следует приписывать основной сборке.

## Пользовательские функции

| Раздел | Что делает | Где реализовано |
|---|---|---|
| Защита | Выбор сайтов, подписанных приложений и срока; просмотр действующего окна; добавление целей; запрос и отмена ожидания выхода | [SystemProtectionView.swift](../../macos-study/Sources/SystemProtectionView.swift) |
| Сеанс | Название текущего дела или выбор существующей задачи, категории Работа/Учёба, запуск, пауза, возобновление и завершение сеанса | [SessionModel](../../macos-study/Sources/FocusDeckApp.swift), [SessionState](../../macos-study/Sources/SessionState.swift) |
| Задача Obsidian | Выбор файла заметки и задачи по устойчивому ID; отдельное явное завершение чекбокса; обновление выбранной заметки | [ObsidianTaskCatalog.swift](../../shared/ObsidianTaskCatalog.swift) |
| Возврат | Сохранённое название/ссылка/необязательный следующий шаг; восстановление контекста после закрытия | [SessionStore](../../macos-study/Sources/SessionState.swift) |
| Обзор | Доступные категории времени и наблюдаемые данные; явная неизвестность и полнота источников | [DailyReport.swift](../../macos-study/Sources/DailyReport.swift) |
| Настройки | Проверка связи со службой, обновление/удаление компонента, сведения о восстановлении после загрузки и локальных источниках | [DeckWorkspaceView.swift](../../macos-study/Sources/DeckWorkspaceView.swift) |

Навигация Защита / Сеанс / Обзор / Настройки поддерживает Cmd+1–4. Обычный конец сеанса не означает выполнение задачи: для изменения чекбокса есть отдельное действие. Отмечается выбранный ID, а не первое совпавшее название. Несовпадение/недоступность заметки должно быть видно пользователю.

Сеанс использует номинальный рабочий отрезок и один пятиминутный перерыв; это параметры продукта, не научная оптимальная дозировка. Восстановленный UI не выдаёт время вне наблюдения за подтверждённую работу. Рабочий сеанс и срок системного запрета — разные состояния.

## Системный запрет

- Служба живёт в root LaunchDaemon `dev.stanislav.focusdeck.protection`, независимо от окна SwiftUI.
- UI допускает срок нового окна от 5 минут до 30 дней. В активное окно можно добавлять цели; это не сокращает прежний срок.
- Штатный ранний выход: запрос ожидания до часа либо до исходного конца окна, если он раньше. Повторный запрос не ускоряет ожидание; отмена запроса сохраняет запрет.
- Состояние и резервная запись хранятся отдельно от пользовательского приложения. Перезагрузка сохраняет остаток, выключенное время его не расходует.
- Удаление службы штатным способом запрещено, пока окно активно. Закрытие интерфейса и остановка сеанса службу не удаляют.
- При выбранных сайтах используется защищённый Chrome с отдельным профилем и обязательными параметрами прокси; другие распознанные браузеры могут быть завершены. До такого режима нужно сохранить их несохранённую работу.
- Приложения выбираются с проверкой подписи/Team ID/requirement. Системные и рабочие сетевые средства исключены политикой.

Реализация: [Service.swift](../../macos-study/system-protection/Service.swift), [Commitment.swift](../../macos-study/system-protection/Commitment.swift), [ManagedBrowser.swift](../../macos-study/system-protection/ManagedBrowser.swift), [BlockedApplications.swift](../../macos-study/system-protection/BlockedApplications.swift).

## Сеть и совместимость

Прокси — CONNECT, без расшифровки TLS и без MITM-сертификата. Выбранные домены и их предусмотренные группы ограничиваются локальным DNS-ответчиком; PF использует отдельный anchor. Программа не должна заменять глобальные правила PF, VPN или маршруты. Состояния DNS/PF/Chrome отражаются раздельно; сообщение о недоступном компоненте не означает доказанную полную защиту.

В 0.12.2 исправлено накопление дескрипторов служебных команд: оба конца Pipe закрываются явно, используются autoreleasepool, ограничение числа клиентов и запас ресурсов только этой службы. Подробности исторического исправления — [отчёт 5 ноября](../MAC-PROXY-RECOVERY-20261105.md). Этот отчёт не является новым сетевым прогоном при публикации исходников.

Основные файлы: [BrowserProxy.swift](../../macos-study/system-protection/BrowserProxy.swift), [DomainResolver.swift](../../macos-study/system-protection/DomainResolver.swift), [ServiceCommand.swift](../../macos-study/system-protection/ServiceCommand.swift), [BrowserRuntimePolicy.swift](../../macos-study/system-protection/BrowserRuntimePolicy.swift).

## Локальные данные и разрешения

| Место | Назначение |
|---|---|
| `/Library/Application Support/FocusDeckProtection` | Root-конфигурация, окно/backup, сведения о браузере и журнал |
| `/Library/PrivilegedHelperTools/FocusDeckProtection` | Установленный помощник |
| `/var/run/dev.stanislav.focusdeck.protection.sock` | Локальный IPC со службой |
| `~/Library/Application Support/FocusDeckStudyBrowser` | Отдельный профиль защищённого Chrome |
| Пользовательская Application Support / FocusDeck и FocusDeckHarness | Контекст сеанса и необязательные локальные компоненты наблюдений |

Эти runtime-данные не входят в Git. Установка/обновление системного компонента требует штатной авторизации macOS. Обычная проверка связи, старт окна и запрос выхода используют уже установленную службу. Выбор файла Obsidian делается пользователем; сохранённая ссылка не даёт права читать весь личный vault при сборке проекта.

## Необязательные и прежние компоненты

В исходниках есть Focus/Shortcuts bridge, localhost receiver, экспорт событий, сбор наблюдаемого контекста и управление добровольным возвращением. Их наличие не означает, что все внешние программы, Shortcuts или каналы настроены. См. [архитектуру](ARCHITECTURE.md), [LocalReceiver](../../macos-study/Sources/LocalReceiver.swift), [FocusShortcutsBridge](../../macos-study/Sources/FocusShortcutsBridge.swift), [RecoveryControl](../../macos-study/Sources/RecoveryControl.swift).

## Ограничения

Произвольный самодельный клиент, web-proxy и сознательное вмешательство владельца с root не объявляются закрытыми обходами. Часовая задержка штатного выхода не доказывает час сопротивления любым административным действиям. Полезность/концентрация не измеряются одним таймером. Внутреннее падение ChatGPT из прежнего разбора не объявляется устранённым этой публикацией.
