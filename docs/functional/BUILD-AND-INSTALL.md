# Сборка, установка и настройки

## Общие условия

Исходники и [обезличенные fixtures](../../integration/fixtures/README.md) достаточны для проверки проекта. Личный Obsidian vault, cookies браузеров, Room-базы, ключи подписи и действующий root-ledger в репозиторий не входят.

Конкретные результаты текущей проверки перечислены в [VERIFICATION.md](VERIFICATION.md). Команды ниже описывают действия разработчика; публикация сама их на телефоне не выполняет.

## Android

Версии фиксируются в [libs.versions.toml](../../gradle/libs.versions.toml), [wrapper](../../gradle/wrapper/gradle-wrapper.properties) и [app/build.gradle.kts](../../app/build.gradle.kts): Gradle 9.7.1, AGP 9.3.2, Kotlin 2.4.10, compile/target SDK 37, min SDK 31; Java target 17. Требуются совместимый JDK и Android SDK с соответствующей платформой. Используйте wrapper проекта, а не случайную системную версию Gradle. В этом срезе модульные тесты проверены с OpenJDK 26.0.2.1; Java target приложения остаётся 17.

Укажите SDK через `ANDROID_HOME` или свой локальный `local.properties` (этот файл игнорируется). Из корня:

```sh
./gradlew :app:testDebugUnitTest :guard:testDebugUnitTest
./gradlew :app:assembleDebug
```

Debug-пакет имеет ID `dev.stanislav.focusdeck.qa` и суффикс версии `-qa`; основной пакет — `dev.stanislav.focusdeck`. APK появляется в `app/build/outputs/apk/debug/`. QA не должен подменять личное release-приложение или использовать личный vault ради проверки.

Release собирается `:app:assembleRelease`. Для подписанной поставки нужен собственный ключ: локальный `keystore.properties` либо переменные `FOCUSDECK_STORE_FILE`, `FOCUSDECK_STORE_PASSWORD`, `FOCUSDECK_KEY_ALIAS`, `FOCUSDECK_KEY_PASSWORD`. Сам ключ и значения паролей не коммитятся. Без нужной конфигурации нельзя считать выпуск подписанным или совместимым с установленной личной сборкой.

После осознанной установки пользователь выбирает роль домашнего приложения, если она нужна, и существующий vault через штатный SAF-диалог. Доступ выдаётся конкретной выбранной папке. Собственную Accessibility/VPN-защиту FocusDeck не включать; Stay Focused остаётся отдельным уже используемым средством.

Сброс телефона, Device Owner provisioning, смена hotspot/Private DNS/VPN и переустановка личного пакета не являются шагами обычной сборки или публикации.

## macOS

Нужны macOS 15+ и установленный Xcode Command Line Tools с `xcrun swiftc`, SDK SwiftUI/AppKit/Security. Скрипт выбирает архитектуру текущей машины.

```sh
bash macos-study/build-system-app.sh
```

Результат по умолчанию — `macos-study/build/FocusDeck System.app`. Можно передать абсолютный альтернативный выходной путь. Скрипт собирает UI и root-помощник, копирует общие ресурсы/иконки и проверяет ad-hoc подпись. Он **не устанавливает** службу и не создаёт системный запрет.

Открыть собранное приложение. Рабочий сеанс и существующую задачу можно использовать отдельно от установки системной защиты. Для выбранной системной блокировки компонент устанавливается из интерфейса с обычной авторизацией macOS; обновление должно сохранять активный ledger. Проверка связи с уже установленной службой не переустанавливает её.

Выбор сайтов, приложений и срока выполняется на странице «Защита». При сайтовом режиме нужен установленный Google Chrome; используется отдельный профиль. Другие распознанные браузеры могут быть закрыты, поэтому сохраните их несохранённые изменения до явного запуска такого режима.

После окончания окна системный компонент можно удалить из настроек. Пока окно активно, штатное удаление недоступно; запрос выхода находится на странице защиты и сохраняет ожидание. Административные обходы не объявляются невозможными. Runtime-файлы перечислены в [MACOS.md](MACOS.md).

Старые `build-app.sh`, user-agent manager и advanced-lab относятся к иным сохранённым конфигурациям. Их нельзя молча подставлять вместо основной System-сборки.

## Obsidian

Плагин — plain JavaScript с готовыми `main.js`, `manifest.json`, `styles.css`; отдельной npm/TypeScript сборки у этого каталога нет.

1. Выберите нужный vault самостоятельно.
2. Скопируйте три файла из `obsidian-plugin/focusdeck-panel/` в `<vault>/.obsidian/plugins/focusdeck-panel/`.
3. Включите FocusDeck среди установленных community plugins.
4. Проверьте пути и форматы заметок в настройках плагина перед записью.

Содержимое vault и `.obsidian` пользователя не переносятся в этот Git-репозиторий. Форматы/команды — в [OBSIDIAN.md](OBSIDIAN.md). Для синхронизации используйте существующую папку Syncthing; настройка транспорта не является автоматической функцией FocusDeck.

## Вспомогательные инструменты

Atlas в `architecture-workboard/` имеет отдельные Node/.NET зависимости и [своё руководство](../../architecture-workboard/README.md). Он не нужен для сборки Android, Mac или установки плагина. Кеши Atlas, Roslyn, npm и готовые бинарные результаты не публикуются.
