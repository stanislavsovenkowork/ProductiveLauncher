# Установка, обновление и восстановление core-сборки

Это локальная промежуточная поставка двух приложений. Точный проверенный охват записан в `VALIDATION.md` поставки. Личный пилот не начат; внешний блокировщик пока не подключён. Сайты и браузеры не блокируются этим ядром.

## Первый запуск

Mac: распаковать архив, открыть `FocusDeck.app`. Сборка подписана ad-hoc для локальной разработки; отключать защиту macOS не требуется. Если система отказывает в запуске, сохранить сообщение об ошибке и проверить подпись/происхождение сборки; не менять общие настройки безопасности. Задачу можно ввести вручную. Чтение существующей заметки подключается отдельно через явный выбор файла.

Android: установить `FocusDeck-Android-QA.apk` штатным установщиком. Это отдельный пакет `dev.stanislav.focusdeck.qa`, который сосуществует с личным FocusDeck. Не удалять личное приложение и не менять приложение главного экрана ради проверки. На первом запуске можно начать с одного ближайшего действия без vault и обязательного дневника. Разрешения уведомлений и необязательного ограничителя приложений включаются отдельно.

Выбрать работу или учёбу, начать сессию. 25 минут — цель; продолжающийся таймер может учитывать работу дольше. Пауза исключается из учёта, возвращение требует явного действия. Остановка таймера не помечает задачу выполненной. Статус «не подключено» у внешней защиты не является ошибкой таймера.

## Обмен и независимые сводки

Обмен включается явно для собственной папки внутри уже настроенного Syncthing. Приложение пишет только пространство `FocusDeck/Telemetry/v1`; не открывает сетевой приёмник для других устройств. Локальная очередь работает при недоступности Mac. Запись файла в папку телефона ещё не означает получение Mac; отсутствие данных отображается отдельно. QA использует отдельный пустой каталог, исключённый из личных сводок.

На этом Mac отдельно установлены локальный обзор, loopback-приёмник и наблюдатель контекста приложений. Они могут работать после закрытия `.app`. Контекст приложения не считается измеренным вниманием. Остановить весь этот сбор с сохранением истории можно явным действием в приложении либо `all-stop.command` в `~/Library/Application Support/FocusDeckHarness/control-runtime`. `start-local.command` запускает его снова только по явному действию. После остановки скрытой переустановки нет.

## Обновление и откат

Перед обновлением остановить активную сессию, закрыть приложение и сохранить предыдущую сборку вместе с её manifest. Mac заменяет только `.app`; данные находятся отдельно в `~/Library/Application Support/FocusDeckStudy`. Android QA обновлять поверх того же QA-пакета с той же подписью. Если подпись отличается, установщик должен отказать: не удалять приложение ради обхода этого отказа.

Миграция непустой Android Room-базы 7→9 проверена на отдельной тестовой базе. Это не обещает обратную совместимость старого APK с новой схемой. Для отката Android хранить согласованную резервную копию данных и прежнюю сборку; не устанавливать старую версию поверх новой базы и не стирать личную историю. На этой стадии личный release не обновлялся. Mac-откат также требует совместимого формата состояния; при ошибке оставить данные на месте для восстановления.

Обновление независимого обзора выполняется отдельно, с проверкой принадлежности задания, резервной копией runtime/config и возвратом прежних файлов при ошибке. Замена `.app` не переустанавливает этот контур.

## Удаление

Mac: остановить сессию, при желании отдельно остановить независимый сбор, закрыть и удалить `.app`. История вне `.app` сохраняется. Android: сначала выключить добровольный обмен/ограничитель в настройках; удалить только QA-пакет, если это цель. Удаление Android-приложения удаляет его приватную базу и очередь; уже опубликованные файлы в собственной папке остаются. Автоматическая очистка этих файлов пока не включена.

Если удалить все участники и независимый контур, автоматический возврат не обещается. Внешних напоминаний без выбранного канала и согласия нет. Экспериментальные root/VPN/NE-компоненты не входят в core-установку.

## Воспроизводимая проверка из исходников

Из корня проекта: `sh tools/verify_harness.sh`. Команда собирает приложения и выполняет профильные проверки, но не устанавливает службы, не включает ограничения и не читает личный vault. Нужны локальные Swift/macOS SDK, Android SDK и JDK; секреты подписи release не требуются для QA. Реальные проверки UI и восстановления связи отмечаются отдельно в отчёте: успешная сборка их не заменяет.
