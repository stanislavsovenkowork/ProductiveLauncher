# Архив исходной Git-истории

`legacy-git.bundle` сохраняет 29 исходных коммитов до объединения незакоммиченных Android/Mac/Obsidian исходников. Проверяется `git bundle verify history/legacy-git.bundle`. Восстановление и отличие от текущего дерева описаны в [REPOSITORY.md](../docs/functional/REPOSITORY.md).
